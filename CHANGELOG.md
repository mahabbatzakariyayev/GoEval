# Changelog

## Unreleased — initial library implementation

- Documentation website with 18 pages, local search, dark mode, mobile
  navigation, code copying, GitHub Pages deployment, and runnable how-to guides.

- Native Go evaluation API with friendly cases, reusable evaluators, typed
  errors, quality gates, concurrent execution, retries, and Go test assertions.
- Deterministic text and tool scoring, embedding similarity, multi-stage model
  judges, custom criteria, rubrics, and decision graphs.
- JSON/JSONL/CSV datasets, persistent reports, compatible HTTP model provider,
  memory/disk caching, experiments, and experimental test-data generation.
- Configuration and input preflight before model calls; malformed or incomplete
  judgments return execution errors; updated tool data replaces saved calls.
- Recorded reference fixtures, local HTTP integration tests, race tests,
  minimum-version checks, and cross-platform CI.

This is a pre-release. See [coverage](docs/coverage.md) for current feature limits.
